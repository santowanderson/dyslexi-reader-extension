# Dyslexia Reader Helper 📚

Uma extensão para o navegador Google Chrome desenvolvida para auxiliar usuários com dislexia a melhorar a legibilidade de textos em páginas da web.

## 📝 Descrição
Esta extensão permite personalizar a exibição do texto em qualquer site visitado. Ela foca em facilitar a leitura através da aplicação da fonte **OpenDyslexic** e do ajuste de parâmetros de tipografia, como tamanho da fonte, altura de linha e espaçamento entre letras.

O objetivo do projeto é proporcionar uma experiência de leitura mais confortável e acessível, permitindo que o usuário adapte o ambiente visual de acordo com suas necessidades individuais.

## ✨ Funcionalidades
- **Fonte OpenDyslexic**: Alternância rápida para uma fonte projetada especificamente para facilitar a leitura por pessoas com dislexia.
- **Ajuste de Tamanho de Fonte**: Controle deslizante para aumentar ou diminuir o texto conforme a preferência.
- **Altura de Linha (Line Height)**: Ajuste do espaçamento entre as linhas para evitar que o texto pareça "amontoado".
- **Espaçamento de Letras (Letter Spacing)**: Controle do espaço entre cada caractere para melhorar a distinção visual.
- **Aplicação em Tempo Real**: As mudanças são aplicadas instantaneamente na página atual sem a necessidade de recarregá-la.

## 🚀 Como Instalar

Como esta é uma extensão em desenvolvimento, você deve instalá-la manualmente seguindo estes passos:

1.  **Baixe os arquivos**: Certifique-se de que todos os arquivos do projeto estão na pasta:
    `C:\Users\wande\OneDrive\Documentos\JavaScript\vanilla-js\extension`
2.  **Abra o Chrome**: Acesse a página de extensões do navegador digitando `chrome://extensions/` na barra de endereços.
3.  **Ative o Modo do Desenvolvedor**: No canto superior direito, ative a chave **"Modo do desenvolvedor"**.
4.  **Carregue a Extensão**: Clique no botão **"Carregar sem compactação"** (Load unpacked) e selecione a pasta onde os arquivos da extensão foram salvos.
5.  **Fixar a Extensão**: Clique no ícone de quebra-cabeça (Extensões) no seu navegador e fixe o "Dyslexia Reader Helper" para facilitar o acesso rápido.

## 📖 Como Utilizar
1.  Navegue até qualquer site da web.
2.  Clique no ícone da extensão na barra de ferramentas do Chrome.
3.  Utilize os controles disponíveis:
    -   Marque a caixa para ativar a fonte **OpenDyslexic**.
    -   Arraste os sliders para ajustar o **Tamanho**, **Altura de Linha** e **Espaçamento**.
4.  As mudanças serão aplicadas automaticamente a todo o conteúdo de texto da página.
